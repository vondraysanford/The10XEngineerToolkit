# Standup Update

```text
Turn my raw notes into a standup update.

Rules:
- Use three sections: Yesterday / Today / Blockers. Use bullets with a
  maximum of 1 line each.
- Start each bullet with the outcome or the ticket, not the activity. Write
  "Shipped TASK-1234 retry fix", not "worked on retries".
- For each blocker, name the person or the decision that is necessary. Name
  the work that waits for it. A blocker without a request is only a
  complaint.
- If my notes show a risk (a slip, a scope surprise), state it plainly in one
  line. Standup is the place where a surprise has a low cost.
- Cut all other content. Do not use filler such as "I continue to work on…".
  Do not include process talk.

My raw notes:
<<<paste notes, ticket links, and half-sentences. A mess is acceptable>>>
```
