# Bug Report

```text
Turn this raw problem description into a bug report with clear actions.

Format:
- Title: give the symptom, the location, and the condition. Write "Duplicate
  invoice emails when retry fires during timeout", not "Email bug".
- Steps to reproduce: write numbered, exact steps from a clean state. If my
  notes do not show the reproduction steps, write the closest known trigger.
  Then mark reproduction as the first investigation step.
- Expected and actual behavior: write one line for each. Use observable facts.
- Environment: give the version or build, the environment name, the user or
  role, and the timestamp with the timezone.
- Impact and frequency: state who has the problem, how often it occurs, and
  the workaround if one exists. This information sets the priority. Do not
  skip it.
- Evidence: refer to the logs and screenshots that I supply. Quote the exact
  error.
- Keep FACTS separate from THEORIES. Put theories in a final section with a
  clear label. A wrong theory that reads as a fact can delay the fix for a
  day.

My raw notes, logs, and screenshots:
<<<paste all the data that you have>>>
```
