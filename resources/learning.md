# Learning: Books and Courses with a Large Effect

This list is not complete. Each entry answers one question: what will you do differently after you read it?

## Craft and career

| Book | What changes after you read it |
|---|---|
| *The Pragmatic Programmer*, Hunt and Thomas | This book gives the mindset layer: tracer bullets, the correct use of DRY, and the "broken windows" principle |
| *A Philosophy of Software Design*, Ousterhout | You will design for *deep modules*. You will measure complexity by cognitive load, not by lines of code |
| *Refactoring*, Fowler | You will change code in sequences of small, safe, named steps, not in large rewrites with high risk |
| *Working Effectively with Legacy Code*, Feathers | You will cut seams into old code and pin its behavior with characterization tests before you change it. Use it with [skills/incremental-migration](../skills/incremental-migration/SKILL.md) |
| *The Staff Engineer's Path*, Reilly | This book is the map for effect beyond your own keyboard. It shows what "10x" means in practice |
| *Accelerate*, Forsgren, Humble, and Kim | You will use research data, not opinions, to argue for CI/CD and small batches |

## Systems and architecture

| Book | What changes after you read it |
|---|---|
| *Designing Data-Intensive Applications*, Kleppmann | This book gives the standard mental model for storage, replication, partitioning, and consistency. It is the most recommended engineering book of its decade |
| *Release It!*, Nygard | This book covers circuit breakers, bulkheads, and timeouts. It shows how systems fail in production and how to design for failure |
| *Learning Domain-Driven Design*, Khononov | This is the accessible modern DDD book. It teaches bounded contexts and ubiquitous language without a 600-page text |
| *The Phoenix Project*, Kim, Behr, and Spafford | This book presents DevOps as a novel. You will recognize the problems in your own organization and know their names |
| [Google SRE Book](https://sre.google/sre-book/table-of-contents/) (free) | This book covers SLOs, error budgets, and the removal of toil. It gives the vocabulary for reliable operations |

## Free courses and interactive resources

| Resource | Why it is useful |
|---|---|
| [PortSwigger Web Security Academy](https://portswigger.net/web-security) | This is the best free security training on the internet. It includes hands-on labs |
| [SQLBolt](https://sqlbolt.com/) | This site teaches SQL fundamentals with interactive exercises. Send this link to each person who starts to learn SQL |
| [Kusto Detective Agency](https://detective.kusto.io/) | Learn KQL through mystery cases. The exercises are enjoyable |
| [Exercism](https://exercism.org/) | Free language practice with human mentors |
| [MIT The Missing Semester](https://missing.csail.mit.edu/) | A class about the shell, git, and tools. Most degree programs do not teach these subjects |

## How to learn from these resources

- Read one book at a time. Apply it immediately to real work. One chapter that you used is better than three chapters that you highlighted.
- Write the summary in your own words (in Obsidian, or in a `til/` folder in a personal repo). When you teach the material, you remember it.
- Read the important books again approximately every 3 years. They give different lessons at each experience level.
