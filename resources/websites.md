# Websites for Your Bookmark Bar

## Daily utilities

| Site | What it is for |
|---|---|
| [regex101.com](https://regex101.com/) | Build and debug a regex with a live explanation of each token. Do not ship a regex without a test |
| [crontab.guru](https://crontab.guru/) | Decode and compose cron expressions in plain English |
| [explainshell.com](https://explainshell.com/) | Paste a shell command. The site explains each flag |
| [jwt.io](https://jwt.io/) | Decode and examine JWTs (do not paste production tokens into a website) |
| [db<>fiddle](https://dbfiddle.uk/) | An SQL scratchpad that runs across engines and versions. It is good for reproducible bug reports |
| [.NET Fiddle](https://dotnetfiddle.net/) | C# snippets that you can run and share |
| [quicktype.io](https://quicktype.io/) | Paste JSON. The site makes typed models (C#, TypeScript, …). This removes much manual work |
| [transform.tools](https://transform.tools/) | Convert between formats: JSON ⇄ YAML ⇄ TypeScript ⇄ … |
| [JSON Crack](https://jsoncrack.com/) | Show a complex JSON payload as a graph |
| [endoflife.date](https://endoflife.date/) | Support and EOL dates for each framework, runtime, and OS. Use this site to plan upgrades |
| [Mermaid Live Editor](https://mermaid.live/) | Draft Mermaid diagrams with an instant preview before you put them in Markdown |
| [DevDocs](https://devdocs.io/) | Unified API documentation for almost all technologies, with fuzzy search. It works offline |

## Reference and deep knowledge

| Site | What it is for |
|---|---|
| [Use The Index, Luke](https://use-the-index-luke.com/) | The best free explanation of database indexing. Read it once, and your queries will improve permanently |
| [refactoring.guru](https://refactoring.guru/) | Design patterns and refactorings with diagrams. It has honest "when NOT to use" sections |
| [patterns.dev](https://www.patterns.dev/) | Modern frontend rendering and component patterns |
| [Design System Checklist](https://www.designsystemchecklist.com/) | An open-source checklist for the plan, build, and growth of a design system. Use it to find the gaps in your component library before your users find them |
| [roadmap.sh](https://roadmap.sh/) | Skill roadmaps for each role. Use them to find your own gaps or to help junior engineers |
| [OWASP Cheat Sheet Series](https://cheatsheetseries.owasp.org/) | Specific "do this" security guidance for each topic (auth, SQLi, secrets, …) |
| [learnxinyminutes.com](https://learnxinyminutes.com/) | A full language syntax refresher on one page. Use it before you return to a language that you did not use in the last year |
| [ohshitgit.com](https://ohshitgit.com/) | Recovery procedures for each git problem, in order of urgency |
| [choosealicense.com](https://choosealicense.com/) | Select an OSS license without the need to read 40 pages of legal text |
