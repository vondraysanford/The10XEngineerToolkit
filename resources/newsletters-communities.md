# Newsletters, Blogs, Podcasts, and Communities

Your inbox space is your attention. Use it with care. If you skip three issues in a row, unsubscribe.

## Newsletters

| Newsletter | Cadence | Why it is useful |
|---|---|---|
| [TLDR](https://tldr.tech/) | Daily | Wide industry awareness in 5 minutes. It is the baseline source for current news |
| [ByteByteGo](https://blog.bytebytego.com/) | Weekly | System design concepts with excellent diagrams. It is useful for interview preparation and for real work |
| [Pointer](https://www.pointer.io/) | Weekly | Curated essays about engineering leadership and craft. The quality is consistently high |
| [Milan Jovanović's newsletter](https://www.milanjovanovic.tech/) | Weekly | Pragmatic modern .NET patterns with real code |
| [Architecture Weekly](https://www.architecture-weekly.com/) | Weekly | A curated selection by Oskar Dudycz about architecture, event-driven systems, and messaging |

## Blogs for your RSS reader

| Blog | Topic |
|---|---|
| [martinfowler.com](https://martinfowler.com/) | The standard vocabulary of software design: patterns, refactoring, architecture |
| [Julia Evans (jvns.ca)](https://jvns.ca/) | Deep, clear explanations of how systems work (DNS, TCP, git). The [Wizard Zines](https://wizardzines.com/) are the best cheat sheets in the industry |
| [Brent Ozar](https://www.brentozar.com/blog/) | SQL Server performance, with direct and humorous explanations |
| [SQLskills](https://www.sqlskills.com/blogs/) | Paul Randal and colleagues. The deepest SQL Server internals content available |
| [Andrew Lock](https://andrewlock.net/) | Careful, detailed articles about ASP.NET Core. This blog explains how .NET internals work |
| [Dan Luu](https://danluu.com/) | Contrarian, data-driven essays about engineering practice and culture |
| [Emil Kowalski (emilkowal.ski)](https://emilkowal.ski/) | UI animation and design engineering. Start with [You Don't Need Animations](https://emilkowal.ski/ui/you-dont-need-animations): it shows when an animation helps the user and when no animation is the correct choice |
| [charity.wtf](https://charity.wtf/) | Observability and engineering management, with strong opinions that stay correct over time |
| [The Morning Dew](https://www.alvinashcraft.com/) | A daily list of .NET and developer links. It is an easy way to stay current |

## Communities

| Community | Why it is useful |
|---|---|
| [Hacker News](https://news.ycombinator.com/) | The front page of the industry. Read the comments for the full story |
| [r/dotnet](https://www.reddit.com/r/dotnet/) / [r/ExperiencedDevs](https://www.reddit.com/r/ExperiencedDevs/) | Practical peer discussion. ExperiencedDevs is a rare career-advice forum with high-quality content |
| [SQLServerCentral](https://www.sqlservercentral.com/) & [DBA Stack Exchange](https://dba.stackexchange.com/) | These sites hold the institutional knowledge about SQL Server |
| Your local user group / meetup | In-person contact gives the highest return on your network time. A talk at a local group is the first step to conference talks |
